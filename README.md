# Answer Trace (concept for WisdomAI)

Unofficial concept by Khushboo Malik. Sample data only, not affiliated with WisdomAI.

A trace panel next to every AI-generated answer: the SQL, the tables it read, how fresh each table is against its load SLA, and what the query cost against a per-tenant scan budget. Stale sources produce a visible warning on the answer.

Live: https://khushboo-malik.github.io/wisdomai-answer-trace/

Plain HTML + JS.
